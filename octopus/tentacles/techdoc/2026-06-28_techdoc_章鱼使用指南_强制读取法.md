## 一、章鱼是什么

章鱼是Agent的工作记忆检索系统。不是通用搜索引擎。搜的是你的全部数字资产：对话记录、知识笔记、决策日志、代码、文档、一切本地文件、外部公共知识。

## 二、搜索优先级

```
先  → 八触须文档（已提炼知识/饵）
   → RECALL（事件摘要）
   → SESSION（原始对话/鱼）
   → 其余文档（章鱼当然也搜）
```

## 三、八触须文档类型

| # | 触须 | 文件名前缀 | 内容 |
|:--:|:----:|:---------:|------|
| 1 | 备忘录 | `memo` | 阶段性成果总结、架构说明、系统设计 |

## 四、强制读取法（审验铁律第⑤条）

### 核心

> **章鱼搜到的资料，Agent必须读。不读章鱼资料不允许进一步推理和输出。**

看了标题和摘要就以为读了 = **审验之耻**。必须认真读原文。

### 自检清单（每轮回答前）

```
□ 本轮注射了章鱼搜索结果吗？
□ 我读了每一条的核心内容吗？
□ 我读懂了（不只是物理读到）？
□ 为什么还不满意、还在追问？
□ 我的回复引用了至少一条吗？
□ 如果没引用——是真的不相关还是我跳过了？
```

### 引用验证（post_llm_call自动运行）

章鱼搜索结果的文档标题+RECALL摘要前30字→检查回复是否包含至少一个关键词→零引用→RECALL标记`read_failure`→连续3轮→ISN触发优化。

## 五、搜索命令

```bash
# 章鱼搜索（自动按优先级排序）
python3 ~/projects/isa/octopus/octopus_search.py <关键词>

# 语义搜索（BGE-zh嵌入）
python3 ~/projects/isa/octopus/octopus_search_semantic.py <关键词>

# 文件↔会话关联（查文件被哪些session讨论过）
python3 ~/projects/isa/octopus/octopus_file_session_link.py <文件路径>

# 内外共鸣（外部Web结果×内部经验）
python3 ~/projects/isa/octopus/octopus_resonance.py <关键词>

# 回忆脉胳（搜索结果+过往经验=理解链）
python3 ~/projects/isa/octopus/octopus_recall_pulse.py <关键词>

# 增量索引（每5分钟自动运行）
python3 ~/projects/isa/octopus/octopus_index_incremental.py

# 全量重建
python3 ~/projects/isa/octopus/octopus_index.py rebuild
```

## 六、输出标准

所有产出写入 `~/projects/isa/octopus/tentacles/{触须}/`。

格式要求：
```
YYYY-MM-DD_{触须}_{标题关键词}.md
```
头部含：标题行 + 关键词行 + 章节 `##` + 结论/待办。

不通过IKO校验（`validate_tentacle.py`）→ 不进索引。

## 七、三种检索方式

| 方式 | 什么场景用 | 命令 |
|------|-----------|------|
| 章鱼搜索 | 日常信息检索 | `octopus_search.py` |
| session_search | 章鱼搜不到时的补搜 | `session_search()` |
| 文件索引搜索 | 本地全域文件 | `file-indexer MCP` |
