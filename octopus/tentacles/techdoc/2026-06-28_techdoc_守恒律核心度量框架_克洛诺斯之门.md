# 守恒律核心度量框架 · 克洛诺斯之门

## 一、背景

跨论文验证的守恒律 `d × r × log(L) ≈ K_W` 在5个decoder家族（Llama-3.2, Gemma-2, GPT-2, Qwen, TinyLlama）中普适，α ∈ [8.5, 11.0] ≈ 10。

**克洛诺斯启示**："P2-5守恒律工程化是1个月后最重要的事——不是边角模块，是IO-S的数学骨架。"

## 二、架构

三层设计：

```
┌─────────────────────────────────────────────┐
│  仪表层: health_dashboard()                   │
│    全系统健康报告、趋势可视化、来源分布        │
├─────────────────────────────────────────────┤
│  主动层: detect_alpha() + detect_trend()      │
│    自适应alpha估计、线性回归趋势、稳定性监测   │
├─────────────────────────────────────────────┤
│  被动层: measure() + from_process()           │
│    每次Process状态变化记录d×r×log(L)          │
└─────────────────────────────────────────────┘
```

## 三、三层详解

### 3.1 被动层（测量）

每次IO-S执行任务后，自动记录一条测量：

```
measure(d=5, r=0.85, L=2048)
  → log2(2048) = 11
  → K_W = 5 × 0.85 × 11 = 46.75
  → deviation = |46.75 - 10×11| / 110 = 0.575 (偏离57.5%)
```

`from_process()` 封装从Process状态的plan_count/success_rate/context_length推算：
- `d ≈ plan_count`（步骤数 = 有效维度）
- `r = success_rate`
- `L = context_length`

### 3.2 主动层（自适应 + 趋势）

**自适应alpha：**
- 从测量数据中重新估计 `α = K_W / log(L)` 的中位数和均值
- 抗离群点：取median+mean平均，裁剪到[5.0, 20.0]
- 最少样本：10条
- 持久化到 `detected_alpha.json`

**趋势检测：**
- 线性最小二乘拟合最近N次测量的 d/r/K_W 变化斜率
- 判定标准：
  - `|d_trend| > 0.5/step` → 维度变化过快
  - `r_trend < -0.01/step` → 正确率下降
  - `alpha_stability > 0.3` → alpha波动

### 3.3 仪表层

`health_dashboard()` 返回完整结构：

```json
{
  "alpha": { "detected": 9.87, "default": 10.0, "auto_tuned": true },
  "measurements": { "total": 150, "window_active": 100, "latest_KW": 46.75 },
  "health": { "avg_deviation": 0.12, "healthy": true, "threshold": 0.20 },
  "trend": { "d_trend": 0.02, "r_trend": -0.001, "K_W_trend": 0.15, "healthy": true },
  "sources": { "manual": 50, "process": 80, "gamma": 20 }
}
```

## 四、syscall API

| 名称 | 功能 | 参数 |
|------|------|------|
| `conservation.measure` | 单次测量 | d, r, L, source, plan_id |
| `conservation.from_process` | 从Process推算 | plan_count, success_rate, context_length |
| `conservation.detect_alpha` | 自适应alpha | — |
| `conservation.detect_trend` | 趋势检测 | window(可选) |
| `conservation.dashboard` | 全系统仪表盘 | — |
| `conservation.summary` | 简要摘要 | — |

## 五、跨模块集成

守恒律通过 `kernel._conservation_monitor` 注册为元监控模块，供其他syscall读取：

- **gamma_monitor** — 从守恒律读取 `avg_deviation` 纳入全局Γ矩阵
- **bits_metric** — 验证器边际价值的权重参考守恒偏差
- **calibrate** — 校准门的d/r/L度量与守恒律共享语义
