# 章鱼八触须 · 输出标准

> 签发人：IKO（立法者+执行者）· 日期：2026-06-28 · 版本：v2.0（终版）
> 关键词：八触须, 输出标准, 合规, IKO, 搜索友好, 命名规范

## 法的声明

**八触须写输标准不是章鱼搜索结果的输出标准。** 它是整个Agent系统所有SA、ZA、Skill系统执行后的书写输出标准。所有产出按此标准书写，章鱼才能从最底层精准抓取有效关联信息。

**IKO职责**：立法者+执行者。不通过IKO校验的文档不进索引。

## 通用规范

### 文件命名
```
YYYY-MM-DD_{触须}_{标题关键词}.md
```

### 必备头部
```
# 标题（含核心术语）
> 作者/签发人 · 日期 · 关键词：词1, 词2, 词3
```

### 搜索友好设计
- **标题**：含核心术语，独立被FTS5命中
- **关键词行**：覆盖同义词
- **章节用`##`**：snippet提取更准
- **结论/待办独立章节**：快速定位

## 八触须格式

| # | 触须 | 文件名前缀 | 章节结构 | 必检项 |
|:--:|:----:|:---------:|---------|:------:|
| 1 | 备忘录 | `memo` | 背景/核心内容/当前状态/决策/待办 | 关键词行+##章节 |
| 2 | PAL | `pal` | 背景/待办清单(优先级)/执行方案/风险 | 优先级标注 |
| 3 | 研究分析 | `analysis` | 问题/方法/发现(3+)/结论/建议 | 原文精读验证 |
| 4 | 情报简报 | `intel` | 摘要/情报详情/来源/行动 | 来源标注 |
| 5 | 执行报告 | `execution` | 任务/代码变更/测试/产出清单 | 结果验证 |
| 6 | 会议纪要 | `meeting` | 参会/讨论要点/待办/分歧 | 决议记录 |
| 7 | 技术文档 | `techdoc` | 问题/架构(图/表)/方案/配置 | 可用性验证 |
| 8 | 决策记录 | `lesson` | 背景/决策/依据/影响/回退条件 | 关键词行+结论 |

## 包拯审计

### 校验器
```bash
python3 validate_tentacle.py <file.md>   # 单文件
python3 validate_tentacle.py <dir/>      # 目录递归
python3 validate_tentacle.py <file> --fix # 修复
```

### 四必检
1. ✅ `# 标题`（FTS5命中基线）
2. ✅ `> ... · 关键词：`（搜索词覆盖）
3. ✅ `## `（至少1个二级标题，信息结构化）
4. ✅ `## 结论`或`## 待办`（决策可定位）

### 退出码
- `0` = 合规，可索引
- `1` = 不合规，不进索引

## 搜索优先级（章鱼读取时）

1. 🔴 八触须文档（已提炼知识）
2. 🟡 RECALL（事件摘要）
3. 🟢 SESSION（原始对话）
4. ⚪ 其余文档（章鱼也搜）
