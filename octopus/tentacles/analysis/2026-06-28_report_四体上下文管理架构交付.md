## 二、IOS 桥接层

### 改动文件

**`~/.hermes/hermes-agent/agent/context_compressor.py`**（+27行）

```python
# 在 compress() 方法 return 之前（L2426）
try:
    from jiak_api import recall_append
    recall_append({
        "type": "compression_event",
        "agent": "context_compressor",
        "compression_no": self.compression_count,
        "content": f"[压缩] 第{N}-{M}轮→摘要, 释放{X}% ({A}K→{B}K), {C}条→{D}条",
        "summary_short": f"压缩#{N}: {C}→{D}条 {A}K→{B}K",
        "model_used": "static_fallback" | self._last_aux_model,
    })
except Exception:
    pass
```

### 效果
- 每次 Hermes 框架压缩后自动写一条 `compression_event` 到 RECALL
- 失败不阻塞压缩流程（try/except）
- 含精确指标：压缩轮次范围、节省百分比、token变化、模型来源
