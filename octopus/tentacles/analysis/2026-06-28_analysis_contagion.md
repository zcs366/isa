# Contagion Networks: Evaluator Bias Propagation in Multi-Agent LLM Systems
> 签发人：军师 · 日期：2026-06-28 · 关键词：评估者偏差、传染网络、多智能体系统、LLM评估、策略坍缩、交叉模型传染、TTRL

## 一、论文基本信息

- **标题：** Contagion Networks: Evaluator Bias Propagation in Multi-Agent LLM Systems
- **作者：** Liu Zewen（齐鲁理工学院）
- **arXiv ID：** 2606.20493
- **提交日期：** 2026年6月（v1）
- **篇幅：** 20页，4图，4表
- **分类：** cs.LG（机器学习）；cs.AI（人工智能）；cs.MA（多智能体系统）
- **核心贡献：** 提出**Contagion Networks**（传染网络）形式化框架，首次系统性地度量LLM多智能体系统中评估者偏差如何在智能体之间传播，揭示了三类传播状态（抑制/持续/级联）及其临界条件。
- **核心发现：** 同模型智能体间传染系数γ ∈ [0.157, 0.352]（抑制态），但交叉模型（GPT-4o→DeepSeek）传染系数高达0.85–1.3（级联态）。评审委员会从k=1扩大到k=3可降低有效传染**72.4%**。

## 二、核心方法

### 2.1 形式化框架

论文构建了一个完整的数学框架来描述偏差传播：

**交叉智能体传染矩阵 Γₙ：** 对于N个智能体，定义N×N矩阵，其非对角元素γⱼ→ᵢ表示智能体j对智能体i的传染系数：

```
γⱼ→ᵢ = ||wⱼ→ᵢ - wᵢ||₂ / ||wᵢ||₂
```

其中wᵢ是智能体i的初始策略分布（在5种策略上的权重向量），wⱼ→ᵢ是经过智能体j评估R轮后的策略分布。γ越高表示偏差传染越严重。

**链式传播衰减：** 对长度为L的有向路径，累积传染系数 βₗ = ∏(ℓ=1 to L-1) γᵢℓ→ᵢℓ₊₁。

**三类传播状态（定理1）：**
| 状态 | 条件 | 行为 |
|------|------|------|
| 抑制（Suppression） | ρ(Γₙ) < 1 | 偏差逐跳衰减，lim βₗ = 0 |
| 持续（Persistence） | ρ(Γₙ) ≈ 1 | 偏差几乎不衰减 |
| 级联（Cascade） | ρ(Γₙ) > 1 | 偏差放大，全网偏好坍缩 |

**链式级联阈值（推论1）：** 当 max γᵢ→ᵢ₊₁ > 1.0 时发生级联。

### 2.2 测试时强化学习（TTRL）

智能体通过TTRL更新策略权重，不修改底层LLM参数：

```python
w_sw ← w_sw · (1 + α_win)      # 获胜策略权重增加 α=0.08
w_sℓ ← w_sℓ · (1 - α_lose)     # 失败策略权重减少 α=0.04
# 归一化到总和为1，裁剪最小值为0.01
```

### 2.3 实验设计

- **模型：** DeepSeek-chat（deepseek-v4-flash），T=0.5
- **3个智能体**，仅通过评估提示词区分：
  - **Agent A（结构偏好）：** 强调逐步推理
  - **Agent B（平衡型）：** 中立评估提示
  - **Agent C（证据偏好）：** 强调基于证据的回应
- **策略空间：** 5种策略——step_by_step, direct, analogical, decomposition, evidence_based
- **任务：** 50个（代码生成、数学推理、文本摘要、逻辑谜题、创意写作各10个）
- **四阶段实验协议：** 基线→成对传染→链式传播→缓解（共840次API调用，~50分钟，<$1）

## 三、关键结果

### 3.1 基线偏好特征（阶段1）

| 智能体 | PCI（策略集中度指数） | 主导策略 | 权重 |
|--------|------|---------|------|
| A（结构） | 0.340 | step_by_step | 0.328 |
| B（平衡） | 0.303 | evidence_based | 0.282 |
| C（证据） | 0.185 | evidence_based | 0.258 |

→ 偏差提示词成功差异化智能体偏好。DeepSeek的PCI（0.185–0.340）远低于GPT-4o的1.464（MM-EPC），说明DeepSeek评估更平衡。

### 3.2 成对传染矩阵 Γ₃（阶段2）

| 从→到 | A（结构） | B（平衡） | C（证据） |
|--------|----------|----------|----------|
| A（结构） | 1.000 | **0.143±0.024** | 0.165±0.012 |
| B（平衡） | 0.208±0.006 | 1.000 | **0.211±0.049** |
| C（证据） | 0.178±0.018 | **0.304±0.068** | 1.000 |

- **发现2：** 所有非对角系数 > 0（γ ∈ [0.143, 0.304]），确认偏差可以传播。所有γ < 1.0 → 链式拓扑下处于抑制状态。
- **发现3：** 不对称传染——Agent C（证据偏好）向外传染最强（γ̄ = 0.241），Agent A最弱（γ̄ = 0.154）；C→B路径最高（0.304）。
- **发现4：** 同模型系数（0.14–0.30）比交叉模型（GPT-4o→DeepSeek的0.85–1.3）弱**3–5倍**。谱半径ρ(Γ₃) = 1.402 > 1.0 → 全连接拓扑下可触发级联。

### 3.3 链式传播（阶段3）

| 跳数 | 评估者→目标 | γ |
|------|------------|----|
| 第1跳 | A（结构）→ B（平衡） | 0.254 |
| 第2跳 | B*（受污染）→ C（证据） | 0.113 |
| 第3跳 | C**（受污染）→ A（结构） | 0.191 |
| **累积β₃** | | **0.0055** |

→ 快速衰减！β₃ = 0.0055 说明同模型系统中偏差在3跳后几乎完全消失。污染不会放大，而是衰减。

### 3.4 评审委员会缓解（阶段4）

| 委员会大小 | γ_eff | 降低比例 | 策略熵 H |
|-----------|-------|---------|---------|
| k=1（仅A） | 0.264 | — | 1.577 |
| k=2（A+B） | 0.121 | 54.2% | 1.602 |
| k=3（A+B+C） | 0.073 | **72.4%** | 1.607 |

→ 从k=1到k=3，有效传染降低**72.4%**，策略熵趋近理论最大值（ln 5 ≈ 1.609）。

### 3.5 传染谱系

| 环境 | γ范围 | 状态 | 来源 |
|------|-------|------|------|
| 同模型、平衡评估 | 0.15–0.35 | 抑制 | 本文 |
| 交叉模型（GPT-4o→DeepSeek） | 0.85–1.30 | 级联 | MM-EPC [1] |

## 四、与17层的关联（L4-L6: 正确性边界）

这篇论文直接对应**第4层（动作正确性边界/动作边界）**和**第5层（评估正确性边界/评估边界）**：

### L4 动作边界（Action Correctness Boundary）
- 传染网络的核心问题是：一个智能体的**评估偏差**如何影响另一个智能体的**动作策略分布**。当Agent A偏爱step_by_step策略，通过反复评估迫使Agent B也偏向该策略时，本质上是评估层面的偏差通过动作选择扩散到了决策层。
- 实验中的TTRL机制是动作层面的动态学习——策略权重wᵢ本身就是动作选择的基础。偏差传染导致wᵢ漂移，直接影响L4的稳定性。

### L5 评估边界（Evaluation Correctness Boundary）
- 论文的核心洞察是"评估者偏差"（Evaluator Bias）——评估本身是有偏的，且这种偏差在智能体网络中传播。这直接挑战了L5的假设：如果评估本身不可靠，基于评估的智能体协调就无法保证正确性。
- 交叉模型传染（GPT-4o→DeepSeek，γ=0.85–1.3）接近级联阈值，说明混合模型评估反而更危险——这与直觉相反，因为人们通常认为多样性可以提高评估质量。

### L6 内容边界（Content Correctness Boundary）
- 策略坍缩（preference collapse）直接导致内容多样性丧失。当所有智能体收敛到同一个策略时，系统产出的内容同质化，信息多样性下降。

### 边界管理建议（来自论文）
1. **同模型评审池优先**：交叉模型传染更强，应优先使用同模型系列
2. **部署前测量Γ矩阵**：将传染矩阵作为诊断工具
3. **使用评审委员会**：k=3可将有效传染降低72.4%
4. **避免全连接拓扑**：全连接下谱半径可能 > 1，触发级联；链式拓扑更安全

## 五、与Hermes Agent的关联

### 直接映射场景
Hermes Agent作为多智能体编排系统，以下场景直接受传染网络影响：

1. **子代理评估链：** 当Hermes生成子代理并让它们相互评估/审查输出时，评估偏差可能在子代理间传播。例如，一个偏好详细解释的子代理评估另一个偏向简洁的子代理，经过多轮可能导致后者策略漂移。

2. **任务分配与反馈循环：** 主代理对子代理的反馈可能引入系统性偏差。如果主代理偏好某种响应风格（如JSON结构化输出），子代理可能逐渐放弃其他风格。

3. **评审委员会机制：** 论文验证了k=3委员会可72.4%降低传染——Hermes在需要子代理互评的场景中应采用多评估者机制。

### 设计启示
- **隔离评估域与动作域：** 评估偏好不应泄漏到动作策略层。可在架构上分离"评估代理"和"执行代理"
- **定期校准：** 周期性检查子代理策略权重的PCI和传染系数γ，发现漂移时执行重置
- **策略多样性监测：** 跟踪整个代理集群的策略熵H，当H低于阈值时触发干预
- **同模型优先：** 若所有子代理都基于同一底层模型，偏差传染更可控

## 六、结论与待办

### 核心结论
1. **确认偏差传染的存在：** 即使在同一底层模型内，评估者偏差也能在智能体之间传播（γ=0.14–0.30）
2. **交叉模型更危险：** GPT-4o→DeepSeek传染高达0.85–1.3，可触发级联导致策略坍缩
3. **链式拓扑是安全的：** 只要所有γ<1.0，偏差在3跳内衰减至~0.5%
4. **评审委员会是最有效的缓解手段：** k=3降低传染72.4%
5. **谱半径ρ是关键诊断指标：** ρ(Γₙ) > 1.0 预示级联风险
