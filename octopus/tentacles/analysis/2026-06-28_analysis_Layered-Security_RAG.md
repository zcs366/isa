# A Layered Security Framework Against Prompt Injection in RAG-Based Chatbots
> 签发人：军师 · 日期：2026-06-28 · 关键词：提示注入、分层防御、RAG安全、输入治理、输出审计

## 一、论文基本信息
- **标题：** A Layered Security Framework Against Prompt Injection in RAG-Based Chatbots
- **arXiv ID：** 2606.19660

## 二、核心方法
提出**三层分层防御框架**，针对RAG聊天机器人的直接和间接提示注入攻击，在检索前、上下文构建时、输出后三道防线实施纵深防御：

1. **第一层：输入筛查（Input Screening）**
   - 基于正则表达式的模式检测库（覆盖指令覆写/角色劫持/提示提取等子类），含Unicode归一化、Base64解码等预处理。
   - 基于MiniLM-L6-v2句子嵌入的轻量语义异常检测分类器，输出注入概率s₁，阈值τ₁由实验校准。三种处置方式：带标记放行、消毒、阻止。

2. **第二层：权限约束上下文组装（Privilege-Constrained Context Assembly）**
   - 将系统提示（T1操作者）、检索文档（T2检索）、用户输入（T3用户）分为三个权限层级，分别插入`[SYS]`/`[RET]`/`[USR]`来源标签。
   - 元指令告知模型标记方案，对检索块执行轻量注入扫描。

3. **第三层：输出审计（Output Auditing）**
   - 策略规则引擎：检测系统提示相似度（防数据泄露）、角色令牌（防指令覆写）、有害内容分数。
   - 语义漂移检测：计算参考合规回答与实时回答的余弦距离，阈值τ_drift=0.40。
   - 持续审计循环：结构化日志+会话级告警+群体级统计异常检测（z检验，p<0.01），月更分类器。

## 三、关键结果
- **攻击成功率（ASR）**：从71.4%降至**11.3%**（降低60.1个百分点）
- **误报率（FPR）**：仅**4.8%**
- **中位延迟开销**：仅**61.2毫秒**（极低额外负担）
- 超越最佳单层基线27.3个百分点，超越NeMo Guardrails 23.8个百分点
- **模型无关性**：在GPT-4o、Llama 3 8B、Mistral 7B上均有效
- 攻击向量覆盖：指令覆写（IO）、数据泄露（DE）、行为操纵（BM）三类

## 四、与17层的关联（L1-L3: 正确性治理）
- **L1（输入正确性）**：第一层输入筛查直接对应L1，在注入指令到达推理引擎前就进行拦截。模式匹配和语义检测双通道设计确保了高召回率，同时保持低误报。
- **L2（决策正确性）**：第二层权限约束上下文组装属于决策层面——通过来源标签和指令层级，确保系统提示的权威性不被用户输入或检索文档覆盖。这是「决策信任边界」的具体实现。
- **L3（工具正确性）**：第三层输出审计作为工具输出的最后把关，检测模型是否被成功注入（即工具执行结果是否被污染），并提供告警和人工升级通道，形成完整治理闭环。

## 五、与Hermes Agent的关联
- Hermes Agent可将其三层防御理念内化为安全基线机制：环境变量`HERMES_AGENT_SECURITY_LEVEL`可对应层级切换。
- 第一层的语义异常检测分类器可直接嵌入Hermes Agent的输入预处理管道，作为system prompt的附加安全层。
- 第二层的权限标签方案（SYS/RET/USR）与Hermes Agent的multi-agent角色系统天然对应——每个子Agent可被赋予不同特权等级。
- 第三层的语义漂移检测可作为Hermes反思（reflection）环节的自动触发器——当输出偏离预期模式时触发重新搜索或用户确认。
- 持续审计循环的统计异常检测机制可与PLUR的反馈回路结合，将注入攻击模式作为engram持久化。

## 六、结论与待办
- **结论**：该分层框架是目前最系统化的RAG提示注入防御方案，三层递进式防护在效果（ASR降至11.3%）、效率（61ms延迟）、误报率（4.8%）三个维度均表现优异。模型无关和无需微调的设计使其具备高实用价值。
- **待办**：① 在Hermes Agent中实现第一层输入筛查钩子（正则库+语义分类器）；② 设计Hermes的权限标签系统（API级别标记子Agent来源）；③ 将第三层输出审计与Hermes反思重试机制打通；④ 评估多层防御在长对话场景下的累积延迟影响。
