## 二、章鱼是什么

**章鱼不是搜索引擎。它是Agent的认知记忆引擎。**

| 不是 | 是 |
|------|----|
| 通用搜索引擎 | Agent工作记忆检索系统 |
| 本地文件搜索工具（Everything/Listary/AnyTXT） | 认知记忆引擎——搜对话+决策+因果链+文件+Web |
| 单域引擎（只有内部或只有外部） | 内外共鸣引擎——公共知识×个人经验 |
| 被动响应 | 主动探索+自动关联+认知回溯 |

## 三、三引擎定位（Google vs Perplexity vs 章鱼）

| 维度 | Google | Perplexity | **章鱼终极形态** |
|------|--------|-----------|-----------------|
| **一句话** | 世界上有什么 | 关于X最值得知道的是什么 | **关于X我经历过什么——以及世界上关于X的最新东西和我有什么关系** |
| **数据域** | 全网公开网页 | 公开网络+实时 | **内外打穿——公共知识+个人经验共振** |
| **核心机制** | 倒排索引+PageRank | 实时搜索+LLM综合+引用归因 | **割裂搜索+内外共鸣** |
| **不可替代** | 规模（百亿页面） | 给答案+归因 | **深度个人认知+内外共鸣+因果链** |
| **致命劣势** | 没有答案/不记得你是谁 | LLM幻觉/无个人记忆 | **规模远小于前两者（但不需要规模）** |

**章鱼不跟Google/Perplexity在规模上竞争。章鱼不可替代的优势只有一点：搜到的结果经过你的个人数据过滤后，变成了只有你才能得到的回答。**

## 四、四引擎对比（Everything/Listary/AnyTXT/章鱼）

| 维度 | Everything | Listary | AnyTXT | **章鱼** |
|------|-----------|---------|--------|---------|
| **搜什么** | 文件名 | 文件名+启动器 | 文件内容 | **全息（文件+对话+决策+因果+Web）** |
| **速度** | 亚毫秒 | 毫秒 | 毫秒 | 1-2秒（多维度的代价） |
| **覆盖** | NTFS文件名 | 自定义目录 | 全盘内容 | **对话+事件+文档+文件+Web** |
| **格式** | 文件名（所有） | 文件名+部分 | 文档全格式 | **所有格式（含OCR+语音+视频元数据）** |
| **中文** | 不支持 | 不支持 | 支持 | jieba+语义 |
| **终极区别** | 文件搜索工具 | 文件搜索工具 | 文件搜索工具 | **认知记忆引擎** |

**章鱼学什么**：
- 学Everything：实时索引（USN Journal监听）
- 学Listary：深度集成（Agent决策时自动触发）
- 学AnyTXT：格式覆盖（PDF/DOCX/图片/视频/音频全格式）

**章鱼超越三者的独特价值（三者做不到的）**：
- 搜"我上周讨论过的那个方案" → session对话
- 搜"为什么当时选A不选B" → 决策因果链
- 搜"这个PDF和三个月前那个实验有什么关系" → 跨时间跨类型关联
- 搜视频/图片/音频内容 → OCR+语音转文字

## 五、终极形态定义

### 核心能力

```
局部记忆图 + 经验回溯 + 认知关联
```

### 具体含义

1. **局部记忆图**：同一主题跨session连接。不是按时间线排列对话——是按主题连接的记忆网。
2. **经验回溯**：搜"为什么选A"→回溯到决策因果链（当时因为X→Y→Z才选了A）。
3. **认知关联**：A话题→B话题→C话题的推理链。不是"相关链接"，是因果链条。
4. **内外共鸣**：外部搜索结果（Web）×内部经验（SESSION+RECALL+文档+文件）→只属于你的回答。
5. **自动触发**：Agent回答问题时自动关联到旧经验，不需要用户说"章鱼搜一下"。
6. **遗忘曲线**：什么该记住、什么该淡化、什么该遗忘——不是全量保留。

### 不可替代的价值

当用户搜"2026年AI顶会关于记忆系统的最新论文"——

```
Google → 100篇论文的链接
Perplexity → 5篇论文的摘要
章鱼终极 → "这篇论文的图2和你三个月前的Δ胶囊实验结果一致。
             同时，它的方法学缺陷与你的守恒律研究有关。
             看这个——你的实验设计.docx 在I盘第3节。"
```

## 七、架构原则

1. **内外同一张网**：公共知识和私人经验不是两个域，是同一张网的两面。
2. **本地优先**：本地文件比外网更容易搜，做不好本地不做外网。
3. **格式广度**：不只是.md——PDF/DOCX/图片/视频/音频全部纳入。
4. **实时增量**：文件变更→秒级索引，不等人说"章鱼搜一下"。
5. **共鸣不是聚合**：外部结果×内部经验=只属于你的回答，不是列表。
6. **联邦兼容**：多Agent共享经验——子贡搜过的文件军师也能搜。

## 八、关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| **本地vs Web优先级** | 本地P0，Web不做深化 | 用户铁律 |
| **文件格式起步** | 纯文本优先（md/txt/py/csv） | 零依赖零配置 |
| **搜索引擎** | Tantivy BM25 | 已在用稳定（中文分词bug刚修） |
| **嵌入模型** | BGE-zh | 已在（d5-zh-v2已下） |
| **增量方式** | 定时5min→事件驱动 | 事件驱动复杂，先跑通定时 |
| **OCR** | pytesseract→easyocr | tesseract轻量先上 |
