## 一、背景

ISN（人格化标准化功能模块系统）是ISA Project人工认知架构的第二层（Brain皮层），负责管理所有技能（Skill）的全生命周期。2026-06-26至06-27完成P0-P2全链路闭环。

## 二、核心架构

### 2.1 三层信息分级

| 层级 | 可见范围 | 内容 | 存储 |
|------|---------|------|------|
| 索引层 | SA可见 | 名/版本/状态 | `index.json` |
| 定义层 | ZA可见·SA不可见 | prompt全文 | `SKILL.md` |
| 元数据层 | ISN可见 | 质量信号/版本史 | `isn.json` |

### 2.2 三系统架构

- **ISA** = Agent本身（大脑皮层·三层）
- **ISN** = 技能系统（技能管理）
- **IO-S** = 治理层（syscall + 法体系）

### 2.3 ZA反馈管道

ZA是skill唯一调用通道，不和用户直接通信。因此质量信号分双源：

- **ZA机械层**：成功/失败/token数/异常类型
- **SA结果层**：用户满意度/纠正次数/重试率
- **ISN聚合**：双源综合判断→触发优化或降级

### 2.4 优化池闭环

```
注册 → 路由 → 执行 → 反馈(Z+SA) → 聚合 → 判断阈值 → prompt v2 → 版本号+changelog → 索引层SA可见
```

## 四、关键技术决策

1. **Skill ≠ Agent** — 人格化skill是功能模块，不是独立Agent。SA是Agent，Skill是SA的工具
2. **prompt不进SA上下文** — Skill prompt只对ZA可见，SA只发goal收结果
3. **tool = skill** — MCP归属ISN管理，与skill统一注册/路由/反馈
4. **存储位置**：`~/isn/`（~550行Python，零依赖）
