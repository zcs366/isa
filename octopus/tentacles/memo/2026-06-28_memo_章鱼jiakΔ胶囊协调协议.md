# 章鱼·jiak·Δ胶囊：关系互动与协调协议备忘录

> 签发人：军师 · 日期：2026-06-28 · 关键词：章鱼, jiak, Δ胶囊, 协调协议, 三层记忆, 协作

## 一、三者定位

| 系统 | 是什么 | 管什么 | 存什么 | 搜什么 |
|------|--------|--------|--------|--------|
| **章鱼** | 工作记忆搜索引擎 | 怎么找信息 | 索引(Tantivy) | 八文档→RECALL→SESSION→FILES→WEB |
| **jiak** | 认知注入管线 | 怎么送+验证 | 卡片(JSON) | 卡片匹配+引用验证 |
| **Δ胶囊** | 三层记忆架构 | 怎么存+延续 | 胶囊(SharedMemory) | 事件→语义→身份三层 |

## 二、关系

```
用户提问
  │
  ▼
章鱼搜索（八文档优先 → RECALL → SESSION → FILES → WEB → Δ胶囊）
  │ 返回搜索结果
  ▼
jiak注入管线（↑）
  ├─ SA快照 → 压缩 → 铁律 → 反馈 → 检索 → 章鱼 → 卡片 → 自检令牌
  ├─ post_llm_call → 引用验证 → octopus_unread检查
  └─ 读到了 → 写入Δ胶囊事件层
  │
  ▼
Δ胶囊三层记忆
  ├─ 事件层：当前session对话
  ├─ 语义层：八文档已提炼知识
  └─ 身份层：强制读取法+审验铁律第⑤条
       │
       ▼
章鱼增量索引（cron每5分钟）→ 八文档更新 → Δ胶囊事件同步
```

## 三、协调协议

### 协议1：搜索→注入（章鱼→jiak）

```
章鱼搜索结果 → jiak pre_llm_call
  ├→ 按优先级排序：八文档>RECALL>SESSION>其他
  ├→ 附带自动摘要（文档标题+RECALL摘要前30字）
  └→ 注入末尾加自检令牌（不可跳过）
```

### 协议2：注入→读取（jiak→Agent）

```
jiak注入的章鱼结果 → Agent阅读
  ├→ 自检令牌：读了？读懂了？引用了？
  └→ post_llm_call引用验证（关键词匹配）
       ├→ 命中→继续
       └→ 零命中→RECALL标记read_failure
             ├→ 连续3轮→ISN触发优化
             └→ 连续5轮→强制停止推理
```

### 协议3：读取→记忆（Agent→Δ胶囊）

```
Agent读完章鱼结果并引用后
  ├→ 关键结论→Δ胶囊事件层（事件记忆）
  ├→ 提炼知识→Δ胶囊语义层（八文档）
  └→ 身份约束→Δ胶囊身份层（强制读取法）
```

### 协议4：记忆→搜索（Δ胶囊→章鱼）

```
Δ胶囊新事件写入
  ├→ 章鱼增量索引（cron每5分钟）
  ├→ 新文档被索引→下一次搜索可命中
  └→ Δ胶囊共振协议→跨session唤醒
```

### 协议5：跨session延续（Δ胶囊→章鱼→jiak）

```
新session启动
  ├→ Δ胶囊共振（HELLO_TTL=24h）→检查身份连续性
  ├→ 章鱼搜索（ReSESSION）→找回上次工作
  ├→ jiak注入（快照+铁律+检索+卡片）→恢复上下文
  └→ 强制读取自检→确保Agent读了延续信息
```

## 四、分工表

| 场景 | 章鱼做的事 | jiak做的事 | Δ胶囊做的事 |
|------|-----------|-----------|-----------|
| 日常搜索 | 五路搜索+排序 | 注入+自检+验证 | 检索事件层 |
| 新session启动 | 搜SESSION找回上次 | 快照+铁律注入 | 身份检查(HELLO) |
| 读到关键信息 | — | 引用验证通过 | 写入事件层 |
| 提炼知识 | — | — | 事件→语义升级 |
| 跨session关联 | 文件↔会话关联 | — | 共振唤醒 |
| 增量更新 | cron每5分钟 | — | 事件同步 |
| 审验失败 | — | octopus_unread标记 | — |
| IDC仲裁 | — | — | 身份层裁决 |

## 五、协议边界

| 边界 | 谁做 | 谁不做 |
|------|------|--------|
| 搜 | 章鱼 | jiak不搜，Δ胶囊不搜 |
| 送 | jiak | 章鱼不送，Δ胶囊不送 |
| 存 | Δ胶囊 | 章鱼不存(只索引)，jiak不存(只卡片) |
| 读 | Agent(被强制) | 三者都不读——读是Agent的事 |
| 验 | jiak(引用检查) | 章鱼不验，Δ胶囊不验 |
| 续 | Δ胶囊(共振) | 章鱼不续(只重建)，jiak不续(只注入) |

## 六、冲突解决

| 冲突场景 | 仲裁者 | 原则 |
|----------|--------|------|
| 章鱼搜不到但jiak说应该搜到 | IDC | 确认搜索关键词后再试一次 |
| jiak注入被Agent跳过 | IDC | octopus_unread→连续3轮→ISN优化 |
| Δ胶囊身份与当前行为不一致 | IDC | 身份层>事件层，先纠正行为 |
| 包拯审计不通过 | IKO | 不合规不进索引 |

## 七、金句

> **章鱼找鱼，jiak上桌，Δ胶囊腌起来慢慢吃。**

> 章鱼没有jiak的管道＝鱼找到了不上桌。
> jiak没有Δ胶囊的腌缸＝上了桌的鱼一天就馊。
> Δ胶囊没有章鱼的搜索＝腌缸里的鱼不知道是哪条河来的。

> 三者缺一不可。缺章鱼→找不到。缺jiak→不读。缺Δ胶囊→不记得。
