# 上下文·会话·章鱼·Δ胶囊：四层关系备忘录

> 签发人：军师 · 日期：2026-06-28 · 关键词：上下文, 会话, 章鱼, Δ胶囊, 四层关系, 流水河床, 身份延续

## 一、四层定位

| 层 | 是什么 | 做 | 生命周期 | 类比 |
|:--:|--------|--------|---------|------|
| **Session** | 当前对话 | 每次对话的回合序列 | 每轮刷新，来去自由 | 流水 |
| **Context** | 工作台 | 装当前回合的所有信息 | 每轮刷新，容量有限 | 工作台 |
| **章鱼** | 河床 | 搜全部数字资产的搜索引擎 | 永久沉积，跨session | 河床 |
| **Δ胶囊** | 脊柱 | 跨session的身份延续+共识 | 跨session，24h TTL | 水库 |

## 二、关系图

```
新session
  │
  ├─── Δ胶囊（身份层）
  │      ├─ HELLO_TTL=24h → 检查身份连续性
  │      └─ 共振协议 → 跨session唤醒
  │
  ├─── 章鱼（河床层）
  │      ├─ 五路搜索：八文档→RECALL→SESSION→FILES→WEB
  │      ├─ 强制读取法：搜到不读白活
  │      └─ 增量索引cron(5min)：新数据自动入库
  │
  ├─── jiak（管道层——连接河床和流水）
  │      ├─ pre_llm_call：章鱼结果→注入→自检令牌
  │      └─ post_llm_call：引用验证→octopus_unread→ISN进化
  │
  ├─── Context（工作台）
  │      ├─ 装章鱼结果+jiak注入+自检令牌
  │      └─ Agent在这里读+思考+引用
  │
  └─── Session（流水）
         ├─ 回合间自由流动
         └─ 关键结论→写入Δ胶囊事件层
```

## 三、协作流程

### 3.1 日常搜索

```
Agent在session中思考 → 需要信息
  ├─ 章鱼搜（五路，八文档优先）
  ├─ jiak注入（章鱼结果+铁律+快照+卡片+自检令牌）
  ├─ Agent在context中读取章鱼结果
  ├─ post_llm_call验证是否引用
  └─ 零引用→RECALL标记→连续3轮→ISN优化
```

### 3.2 跨session延续

```
上线 → 新session
  ├─ Δ胶囊检查身份(HELLO)：'你还是昨天的你'
  ├─ 章鱼搜昨天session：'昨天讨论过什么'
  ├─ jiak注入到当前context
  ├─ Agent读到→不用从头解释自己是谁
  └─ 关键结论写回Δ胶囊→身份连续
```

### 3.3 发现重要信息

```
章鱼搜到一篇关键文档
  ├─ jiak注入+自检
  ├─ Agent读了+引用了
  ├─ 关键结论→Δ胶囊事件层
  ├─ 章鱼增量索引(cron 5min)→下次可搜
  └─ Δ胶囊共振→相关联的Agent也能知道
```

## 五、金句

> **Session是流水，Context是工作台，章鱼是河床，jiak是水管，Δ胶囊是水库。**
> 流水过来去自由，工作台够不够用另说——河床永久存着，水管实时供应，水库确保你下次来还有水喝。

> **章鱼找鱼，jiak上桌，Δ胶囊腌起来慢慢吃，session是这顿饭。**

> 缺章鱼→找不到鱼。缺jiak→鱼上了桌不张嘴。缺Δ胶囊→下顿忘了上顿吃的什么。缺session→没地方吃饭。
