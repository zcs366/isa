# 章鱼本地搜索系统

> 八只触角 · session 工作记忆 · 不是成品文档

## 设计哲学

**PAL 管方向（往哪走），章鱼管记忆（走到哪了）。**

成品文档（翻译完的书、写完的论文）在 wiki 里——信息极度集中、标准、易找。
章鱼管的是 **session 产生的工作记忆**。

## 八触角 · 两刀分清

```
                   对自己              对外部
       过去     ①备忘录(石碑)       ④情报简报(雷达)
       未来     ②PAL(路标)          ⑤研究分析(解剖)
       规则     ⑥联邦法(宪法)       ⑦审查报告(镜子)
       杂项     ③决策记录(刻痕)     ⑧问题清单(地图)
```

## 八种问题 → 八种触角 → 章鱼秒搜

| 你问             | 章鱼搜到 | 触角 | 隐喻 |
|------------------|----------|------|------|
| "现在什么状态"   | 备忘录 | memo | 石碑 |
| "接下来做什么"   | PAL | pal | 路标 |
| "为什么这样选"   | 决策记录 | decision | 刻痕 |
| "外面发生什么"   | 情报简报 | intel | 雷达 |
| "那是什么"       | 研究分析 | analysis | 解剖 |
| "规则是什么"     | 联邦法 | federal_law | 宪法 |
| "做得对不对"     | 审查报告 | audit | 镜子 |
| "还有什么没解决" | 问题清单 | issues | 地图 |

## 与 wiki 的区别

| 维度 | 章鱼 tentacles | wiki |
|------|---------------|------|
| 来源 | session 工作记忆 | 指令要求的成品 |
| 信息密度 | 中（过程记录） | 高（极度浓缩） |
| 时效性 | 强（今天的事） | 弱（长期有效） |
| 查找方式 | FTS5 全文搜索 | 标准路径+标签 |
| 示例 | "今天的讨论决定了X" | "《守恒律》论文全文" |

## 文件命名

```
YYYY-MM-DD_{tentacle}_{标题}.md
```

## 使用

```bash
python3 ~/projects/isa/octopus/octopus.py write memo "标题" "内容"
python3 ~/projects/isa/octopus/octopus.py search "关键词"
python3 ~/projects/isa/octopus/octopus.py list [tentacle]
python3 ~/projects/isa/octopus/octopus.py index
```

## 铁律

1. **不是成品文档。** 翻译完的书、写完的论文 → wiki。
2. **session 产生的。** 讨论、分析、决策、进展 → tentacles。
3. **随时可写。** SA 在 session 中随时按格式写。
4. **FTS5 索引。** 写入即索引，立刻可搜。
5. **不删除。** 只追加+归档。
